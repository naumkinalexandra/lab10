# Промпт 1 — интерфейс
Создай минималистичный русскоязычный HTML/CSS/JavaScript интерфейс для учебного FastAPI ML-сервиса. Получай признаки через GET /schema, динамически строй форму, отправляй JSON в POST /predict и показывай ответ. Добавь загрузку CSV через POST /predict-from-csv, обработку ошибок, адаптивную вёрстку и предупреждение об учебном характере прогноза. Не выдумывай названия признаков.
